# Lab 5 – Intro to React (CSE343 Web Development)

A comments section made with React and Vite: post a comment and like comments.

## Run it

```bash
npm install
npm run dev
```

Then open the link Vite prints (usually http://localhost:5173).

## Files

- `src/App.jsx` – the components
- `src/main.jsx` – puts `<App />` on the page
- `src/index.css` – the styles
